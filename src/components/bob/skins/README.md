# Bob skins

`registry.ts` is the authored catalogue. Each stable ID has localized names, body/eye/outline colors, a material recipe, and an optional quest or quest-stack requirement. Skins are independent of the world/UI theme; White and Pastel retain their original body and outline theme colors. Pastel, Peach, Mint, Lilac, and Sky blue use pure black eyes. Black has a charcoal body and white eyes. Peach, Mint, Lilac, Sky blue, and three Neon colors are free. Saved `neon` IDs still resolve to Moon; saved `stripes` IDs resolve to Disco with the original all-routes quest gate.

Add future skins to `BOB_SKINS`. For a hidden unlock, use `unlock: { quest: "quest_id" }` or `unlock: { stack: "stack_id" }`. The shop Skins category shows incomplete skins as locked cards without revealing the requirement. Both the shop action and saved-game selection action enforce the gate. `useBobSkin` supplies White if the selected ID is unknown or its requirement is incomplete, including while quest data hydrates. Existing completed quests qualify immediately. Full-size shop previews are transient: Back, closing the shop, and reloading clear the preview without changing the equipped skin.

`material.ts` uses a shared three-tone ramp and one toon shader for all skins. Changing a skin updates the existing material and uniforms. Moon uses graphic crater bowls and rims; Disco has mirrored tiles with animated reflections; Watermelon has green rind stripes; Wood has flowing grain and knots. Chrome has procedural silver studio reflections in four crisp cel-shaded bands, softly blended highlights, and animated surface glints. Glass remains static and translucent. Water is a separate translucent shell with an analytic interior water plane, a moving waterline, and bubbles. Jelly is a translucent lime-green volume with soft highlights, suspended bubbles, and gently shifting depth. Water, Chrome, Disco, and Jelly animation respect the effects and reduced-motion preferences. Bounds normalize the patterns across Bob forms without UV seams.

Reward gates: Disco requires `routes_purchased_3`; Watermelon requires `total_taps_1000`; Chrome requires `total_taps_10000`; Glass requires the complete `shop_item_categories` stack. Wood costs 50,000 points, Water 100,000, and Jelly 250,000. Paid ownership is saved in `purchasedBobSkinIds`; purchases charge once and equip the skin. The replacements retain saved IDs `denim`, `leather`, `gold`, and `tnt` so prior selections, unlocks, and ownership carry over. Removed or unknown saved skin IDs safely resolve to White.

`previews.ts` only resolves saved PNG paths. The shop never creates a thumbnail WebGL context. To refresh images, open `scripts/render-skin-previews.html` on the existing development server and save the rendered bundle with `scripts/save-skin-previews.ts`. The renderer mounts the production `SceneLens` and `BlobForm`, uses the shared Shop camera pose and standard round Bob face, then crops the finished canvas pixels into transparent 160px PNGs. It does not zoom the lens, move the camera, or duplicate the fisheye projection. Glass retains its original rim and highlight recipe. Keep the large 3D preview and existing shop controls.

Foreground outlines are handled separately by `components/ForegroundOutlines.tsx`. Mark a 3D group with `userData={{ foregroundOutline: "bob" | "counter" | "foreground" }}`. Set it to `false` for scenery/effects nested inside foreground groups. Untagged scenery is excluded. Accessories explicitly opt out except the clown nose; active level geometry opts out too. Books set `outlineThickness: 0.0025`, one fifth of the standard foreground width. Do not add individual Drei `Outlines` shells to models.

The outline manager indexes hierarchy additions/removals through Three.js events. Each frame it checks explicit scope/width owners and outlined candidates, rather than traversing the whole scene. Existing scope tags can change at runtime; if imperative code introduces a tag on a previously untagged attached object, call the manager's `invalidate(object)` method. Derived geometry is owned by the manager and shared by outlines using the same source geometry. Text replacements reuse the shell/material; toggles detach and reuse shells, and disabling all categories skips frame updates. Hidden sources defer outline creation and geometry replacement until visible.
